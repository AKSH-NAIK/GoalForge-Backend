

# GoalForge Backend

This repository contains the backend code for GoalForge, an AI-powered platform that helps users set, track, and achieve their goals through personalized learning and achievement roadmaps.

The backend provides the core API and logic for generating week-by-week plans, tasks, and AI tips based on user goals and preferences. It powers the GoalForge frontend ([GoalForge-UI](https://github.com/AKSH-NAIK/GoalForge-UI)) and the live web application ([goalforgeweb.vercel.app](https://goalforgeweb.vercel.app/)).

**Key Points:**
- Generates personalized roadmaps and tasks using AI
- Integrates with the GoalForge frontend for a seamless user experience
- Designed to help users achieve their goals step by step

For more information and to try the platform, visit the [live site](https://goalforgeweb.vercel.app/) or explore the [frontend repository](https://github.com/AKSH-NAIK/GoalForge-UI).
